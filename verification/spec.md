# Verification contract v2

The current contract is bounded, deterministic and CPU-only. No model participates in calculation or checking. App verification is automatic for filled tables/charts; the legacy structured-certificate CLI is only a development aid. See [usage and boundaries](../doc/verification.md).

1. Preserve the input workbook's bytes. Every report field is either an explicit raw source cell, a declared normalization of source labels/bounds, or a fixed schema header. No population bound is a cost.
2. For every recognized bounded block, include each supported record exactly once in source order; page partitions cover `[0,n)` without gaps or overlaps. Unknown source semantics remain outside the contract rather than guessed.
3. Never add rate rows, organization totals and their children, or crosscut subsets together. The initial report is descriptive. Original inconsistent totals remain intact and require a visible warning with original and component-derived values.
4. Missing bounds remain unknown. Missing cells, literal dashes and numeric zero are distinct; a specific source accounting zero section may legitimately render a numeric zero as a dash or blank. No global dash-to-zero conversion is allowed.
5. The exact sum checker accepts only explicit disjoint atom scopes with the same measure/kind/unit/period and exact coverage. This proves arithmetic relative to supplied scope assignments; actual business membership is an assumption.
6. Growth oracle follows the existing `(now-base)/abs(base)` policy. Base0 is undefined. Small-domain comparisons allow1e-12relative/absolute float tolerance; they are not exact-rational equivalence for all Python floats.
7. A certificate is untrusted input. Its source hash, role/reference sequence, headers, language, scope and page coverage are checked against a separately implemented raw-XML oracle, then against saved tables. A PASS with source findings is not a clean source-data verdict.
8. Normal supported inputs must produce nonempty results. Refusing every input is not success. Unknown formats, empty evidence, unsupported schemas and unexplained extra charts cannot pass the report checker.

9. Automatic verification runs on serialized preview and final staged bytes. Source drift, captured-value mismatch, changed shape binding/cache/embedded reference, or failed internal verification blocks publication without the ordinary error-confirmation override. The source snapshot is shared between generation preview and save. Final staged bytes must match the verified serialization and the output must be new.
10. Unsupported source/point expressions are explicitly partial and never erase known failures in other fields. Integers compare exactly; noninteger serialization comparisons use2ULP, while explicit aggregate recipes use exact rational intermediates, a checked decimal-decoding bridge and one final numeric conversion. No operation-count multiplier applies to aggregates. No universal floating-point error theorem is claimed.
11. Actual generated integer sum/equality/tolerance/rational-cross-product/signed-rounding code is verified by Dafny4.11.0 and called by the app. See [proof contracts and provenance](proofs/README.md). The compiler class AST is preserved after removing unused imports; bridges have type checks and adversarial tests.

Trusted boundaries: the schema specification, explicit source meaning, source selection/interpreted header recipes, format rendering, Python/Fraction/Decimal/ZIP/XML implementations, checker implementation, source authenticity and proof toolchain/conversion bridges. Tests reduce implementation risk but do not formally prove these boundaries. Office rendering is inspected separately. Universal correctness, all workbooks, all formulas and intent alignment are not claimed.

Broader mathematical statement outside the current kernel: for finite atom set U and selected groups C whose extents E(c) are pairwise disjoint and whose union is S, if each group value equals the sum of its atom values, then `sum(c in C, sum(u in E(c), x(u))) = sum(u in S, x(u))`. Such a theorem alone would not prove inferred spreadsheet membership or business semantics. Current structured organization reports deliberately preserve records without performing this hierarchy sum.

12. Supported BIFF8/XLS and XLSB caches are decoded independently, not recalculated. Explicit XLSX row-outline levels preserve original records without inferred membership sums; the grouping caveat is mandatory. Signed decimal rounding uses generated RoundScaled after validating its floor-quotient precondition; source/conversion/scaling and source conversions and unrelated floating statistics are not thereby proved. SumBound proves the triangle bound for supplied integer-scaled row-decoding errors, and its generated implementation is used by the automatic aggregate audit.

13. Bounded BIFF2/3/4 raw sheets, BIFF5/95 codepaged workbooks and BIFF5/8 RSTRING values are reconstructed independently. Nested HTML tables become separate sheets with checked parent markers and retained parent tail cells; no nested-value flattening or inferred totals. Unsupported workspace/continuation/DOM forms remain explicit limitations. A separate human trial remains excluded by user choice. The later exact-EXE Office-free Windows 10 VM test was completed; see [environment evidence](../doc/testing-alternatives.md).
