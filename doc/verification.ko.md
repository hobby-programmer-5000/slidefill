# CPU 검증기

표·차트 자리표시자를 채울 때 **앱 내부에서 자동으로 검증**합니다. 구조화 단가표·조직표도 포함합니다. 로컬 모델·GPU·별도 검증기 창·사용자 명령이 필요하지 않습니다. 미리보기와 생성 모두 같은 `core.run` 검증 경로를 거칩니다.

## 앱에서의 동작

- **완료:** 채운 값과 저장된 표·차트 표현을 대조했습니다. 지원하는 XLSX 원본 계산식은 원시 XML로 독립 검산합니다. 선택한 업무 범위와 해석한 이름은 확인해야 합니다.
- **부분 검증:** 독립 검산하지 못한 형식이나 표현이 있어 앱에 표시합니다. 전체 검증으로 표시하지 않으며, 다른 곳의 확정된 오류는 계속 저장을 차단합니다.
- **저장 차단:** 원본 변경, 값·분류·계열·점 개수·캐시·내장 엑셀·필수 원본 경고의 불일치를 찾았습니다. 해당 미리보기에서는 생성 버튼을 끕니다. 원본을 다시 열고 미리보기를 실행하세요. 일반적인 ‘그래도 만들기’ 확인으로 우회할 수 없습니다.

직렬화한 미리보기를 검사하고, 저장 후보 파일의 내용과 원본 지문을 다시 확인한 뒤 새 결과로 확정합니다. 기존 결과는 덮어쓰지 않습니다. 일반 앱 사용에서 인증 JSON이나 원본 사본을 추가로 만들지 않습니다. 미리보기에서 사용한 원본 스냅샷을 해당 저장 단계에서도 유지합니다.

일반 분류 차트·날짜 축·산점도의 계열명, 분류/좌표, 빈 점, 점 개수, 캐시와 내장 XLSX의 참조 셀을 대조합니다. 직접 범위, 일반 최신 시계열, 분리 날짜, 조건별 합계·평균·건수·비율·곱, 순위와 분모가 명확한 구성비에는 원본 계산 근거가 연결됩니다. 범위 선택·계층 해석·숫자 서식은 테스트와 신뢰가 필요한 경계입니다. 독립 리더가 없는 형식이나 재구성할 수 없는 표현은 부분 검증으로 표시합니다. 버블 차트는 명시한 X열 뒤의 Y·크기 열 쌍을 받습니다. 크기는 음이 아니어야 하고 계열마다 완전한 숫자 점이 하나 이상 필요합니다. 읽지 못하거나 불완전한 점은 일관되게 제외하며 크기 캐시와 내장 셀도 검사합니다. 독립 리더는 XLSX 계열·이름을 바꾼 XLSX 내보내기·CSV/TSV/TXT·지원하는 ODS 값 유형을 읽습니다. 지원하는 BIFF2–5/8 XLS·XLSB 셀/캐시는 독립 디코더로 검사하며 미지원 바이너리 기록/작업공간 변형·미지원 ODS 기간 문법·그 밖의 알 수 없는 표현은 부분 검증으로 남습니다. HTML·구분 텍스트 XLS 내보내기도 검사합니다. [바이너리·그룹·반올림 경계](binary-verification.ko.md)를 참고하세요. 텍스트·ODS 독립 재구성에는 셀 200만 개 예산이 있으며 앱의 스프레드시트 리더를 호출하지 않습니다.

정수 비교는 정확히 일치해야 합니다. 소수·실수의 직렬화에는 이진 부동소수점2ULP 예산을 적용하고, 명시한 그룹 집계는 정확한 유리수 중간 계산과 마지막 한 번의 숫자 변환을 사용하며 원본 피연산자로 독립 재구성합니다. 집계의 연산 수에 따른 ULP 배수는 없습니다. [집계 계약](binary-verification.ko.md#정확한-집계와-원본-디코딩-오차)을 참고하세요. 이는 실제로 강제하는 비교 정책이며 부동소수점 오차 자체의 형식 증명은 아닙니다. 큰 금액의 단위 오류를 숨길 수 있는 일괄 상대 오차를 사용하지 않습니다.

## 특수상황과 보고서에 남는 설명

| 상황 | 현재 앱·보고서의 동작 | 사용자가 확인할 내용 |
|---|---|---|
| 단가표의 상한이 없거나 합계가 구성 항목과 다름 | 원본 값을 유지하고 구조화 보고서의 설명에 상한 미기재 또는 원본·구성 합계 불일치를 적습니다. 없는 상한을 무한대로 추정하지 않습니다. | 적용할 인원 구간·학교별 예외. 앱이 원본 합계를 고쳐 주지는 않습니다. |
| 조직 합계와 부서·직종이 함께 있음 | 원본 기록과 설명을 유지하며, 계층을 추정하거나 상위 합계와 하위 항목을 함께 더하지 않습니다. | 실제 업무 범위에 포함할 기록. |
| 회계연도 종료월 불명, 불완전한 기간, 확인하지 않은 자동 선택 | 기존의 조건부 문장·설명을 쓰거나 비교를 유보합니다. | 실제 결산월·대상 날짜·선택한 지표. |
| 독립 검산하지 못하는 원본 형식·표현 | 앱에 부분 검증을 표시하고 가능한 검사는 계속합니다. | 검산하지 못한 원본 계산과 선택 범위. 다른 곳의 확정된 오류는 계속 저장을 막습니다. |
| 원본 변경, 차트·캐시·내장 엑셀 변조, 필수 원본 경고 누락 | 저장을 차단하며 일반적인 ‘그래도 만들기’ 확인으로 우회할 수 없습니다. | 의도한 원본을 다시 열고 원인을 바로잡은 뒤 미리보기하세요. |

예를 들어 식품비가 10, 운영비가 20, 원본 합계가 35이면 보고서는 35를 유지하고 구성 합계가 30이라는 경고를 남깁니다. 검증 통과는 이 값과 필수 경고를 정확히 보존했다는 뜻일 수 있으며, 원본 합계가 옳다는 인증은 아닙니다.

보고서 설명에는 수치를 해석하는 데 필요한 정보와 지원하는 구조화 원본의 문제를 남깁니다. 모든 앱 경고가 슬라이드에 인쇄되는 것은 아닙니다. 자동 검증의 완료·부분 검증·차단 상태는 앱에 표시하며, 보고서 전체를 ‘수학적으로 인증’하는 도장은 붙이지 않습니다. 일반 생성에서 PPTX에 증명 코드·내부 원본 계산 근거·인증서를 추가하지 않습니다. 받는 사람도 검증기를 실행할 필요가 없습니다. 이 설명은 현재 동작을 기록하며 새 내장 기능을 추가한다는 뜻은 아닙니다.

검사가 필요한 이유, 수학적 알고리즘, 코드별 역할과 유지보수 검사는 [검증 설계](verification-design.ko.md)를 참고하세요. 형식 증명의 재현 방법은 [별도 안내](../verification/proofs/README.ko.md)에 있습니다.

## 개발자가 재현하는 명령

프로젝트 폴더에서 실행합니다.

```powershell
& .\.venv\Scripts\python.exe -X utf8 -m verification selftest
& .\.venv\Scripts\python.exe -X utf8 -m verification generate C:\data\rates.xlsx C:\data\check-001 --lang ko
& .\.venv\Scripts\python.exe -X utf8 -m verification check C:\data\rates.xlsx C:\data\check-001\report.pptx C:\data\check-001\certificate.json
```

**새 출력 폴더**를 지정합니다. 기존 폴더는 거절하며 `template.pptx`, `report.pptx`, `certificate.json`, `checks.json`을 만듭니다. 원본에는 쓰지 않습니다. 비공개 원본의 인증 기록과 결과물도 비공개로 보관하세요. 종료코드0은 선언한 검사 통과,1은 검사 실패,2는 명령 실행 불가입니다. 실패하면 새 출력 폴더에 근거가 남을 수 있습니다. 내용을 확인하고 다음 실행에는 다른 폴더를 지정하세요.

이 독립 실행형 구조화 표 인증에서는 `result`와 `source_findings`를 함께 읽습니다. PASS는 원본 값과 경고를 보존했다는 뜻이며 원본 자체가 정확하다는 뜻은 아닙니다. 이 기존 CLI 인증의 계약은 구조화 표로 제한됩니다. 일반 차트는 위의 앱 내부 자동 검증을 사용하며 사용자가 CLI를 실행할 필요가 없습니다.

## 지원하는 표

- 단가표: 인접한 최저/최고 또는 min/max 열과 식품비/운영비/계 또는 food/operations/total 머리글이 필요합니다. 유효한 정수 인원 구간이2개 이상이어야 합니다. 학교급별 비용 묶음과 이름이 있는 학교별 예외를 보존합니다. 빈 상한을 무한대로 추정하지 않으며 단가들을 지출액으로 합산하지 않습니다. 구성 항목과 다른 원본 합계도 원본 값으로 유지합니다.
- 조직표: 현원/정원 또는 headcount/quota 행, 두 행 위의 기관명, 합계·일반직·별정직·정무직 하위 머리글을 읽습니다. 기관명이 세로 병합되고 현원이 한 칸인 경우도 읽습니다. 상위 합계와 부서를 각각 원본 기록으로 표시하며 숫자가 맞는다는 이유로 계층을 확정하지 않습니다. 다른 층위를 함께 순위나 합계로 만들지 않습니다.
- 명시적 그룹: 인접한 항목·값 역할 머리글과 실제 XLSX 행 그룹 메타데이터가 있으면 원본 행·수준·값을 설명 표로 보존합니다. 상위/하위 값은 더하지 않으며 필수 그룹 주의사항을 삭제하면 보고서를 차단합니다.
- 실제 내용이 있는 셀에서 명시적인 스키마 머리글을 찾아 300행·80열 밖도 탐색하며 빈 서식 영역을 고정 사각형으로 훑지 않습니다. 표는8개 기록씩 나눕니다. 해석 문법은 여전히 제한되며 모호한 계층은 추정하지 않습니다. 원본 이름의 언어는 유지하고 생성 머리글·해설·확인은 영어/한국어를 지원합니다. 빈칸을0으로 바꾸지 않습니다. 구조화 보고서는 생성 전에 확인받고, 제외한 다른 시트 수도 표시합니다.

독립 검증은 지원 구역의 누락·행 순서·수치 역할·셀 참조·원본 해시·표 머리글·손실 없는 수치·필수 원본 경고를 확인합니다. General, 정수/천 단위, 소수 둘째 자리 형식과 회귀 사례의 특정 정수 회계 서식을 검사합니다. 그 밖의 형식은 조용히 통과시키지 않고 검증 실패로 남깁니다. 모든 업무 의미, 전체 Excel 수식 계산, 임의 숫자 서식과 Office 배치를 증명하지 않습니다.

## 파일 역할과 보장 수준

`layouts.py`가 앱의 제한된 표 해석을 맡습니다. `verification/pipeline.py`가 보고서 생성과 인증 기록을 연결하며 이 어댑터만 앱을 import합니다. `rawxlsx.py`, `oracle.py`, `output.py`, `check.py`는 앱의 해석·계산 함수를 호출하지 않고 근거를 읽습니다. `arithmetic.py`는 Fraction·명시적인 Decimal 반올림으로 기준 계산과 겹치지 않는 범위 합계를 검산합니다. 그 밖의 앱 통계·선택 계산에는 부동소수점 연산이 남아 있습니다.

`selftest`는 정수−25..25의 변화율, 작은 닫힌 구간의 경계, 원자4개를 그룹3개에 배정하는81가지 전체를 검사합니다. 표 이동, 양 언어, 원본 경고, 누락·중복 참조, 손상 파일과 덮어쓰기 거절도 확인합니다. 변이 검사는 출력 값 변경·행/경고 삭제·차트 캐시와 내장 엑셀의 별도 손상을 주입합니다. 차트 검사 모듈에는 정답이 정해진 합성 사례가 있지만 보고서 CLI의 일반 차트 인증은 아직 지원하지 않습니다.

테스트와 범위를 정한 전수 검사에 더해 [실제 Dafny 핵심 증명](../verification/proofs/README.ko.md)을 연결했습니다. 앱은 생성된 정수 합산·목록 일치·허용 오차 비교·유리수 교차곱 코드를 호출합니다. 양의 분모를 전제로 유리수 변환 자체도 증명했으며 Fraction 정규화·값 추출과 허용치 정책은 테스트·신뢰 경계로 남습니다. Dafny4.11.0으로 계약과 종료를 검증했고 잘못된 구현 변이는 거절됐습니다. **앱·표 해석·Office 전체의 전 입력 증명은 아닙니다.** 컴파일러·솔버·Python·정수/유리수 변환·원본 계산 근거·선택과 서식은 신뢰 경계로 남습니다. 실제 회사 파일·사람의 EXE 시험도 별도 근거입니다.

## 라이선스

새 원본 코드는 기존 프로젝트 MIT를 따릅니다. 의존성·모델·가중치·제3자 소스를 추가하지 않았습니다. 기존 구성요소 고지는 그대로 적용됩니다. 공개 회귀 자료와 연구 PDF는 배포물에 넣지 않으며 공유용 예시는 합성 자료를 사용합니다.
