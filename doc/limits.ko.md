# 지원하는 배치와 남은 검증

자동 선택은 제안입니다. 생성 전에 화면의 시트, 수치, 기간, 조건과 단위를 확인하세요. 경고가 없다고 선택한 수치가 업무 질문에 맞는다고 증명된 것은 아닙니다.

[수식·텍스트·정밀도 개선](reliability-hardening.ko.md)은 아직 릴리스하지 않은 개발 소스이며 확정된 불일치와 부분 검증 모두 저장을 거절합니다. 아래 Windows·Office 근거는 배포된 v0.3.0 산출물의 기록이며 변경된 소스나 새 EXE의 시험은 아닙니다.

## 지원 범위

- 인원 구간별 비용 단가표와 기관·직종이 반복되는 조직표는 원본 셀과 연결된 설명 표로 만듭니다. 생성 전에 확인받고 빈 상한과 원본 합계 경고를 유지합니다. 단가를 지출액으로 합산하거나 조직 층위를 섞지 않습니다. [CPU 검증기와 정확한 지원 경계](verification.ko.md)를 참고하세요.

- 월이 가로로 놓인 표는 기간 행과 수치 행을 식별할 수 있으면 읽습니다. `최신:월별!1,2`처럼 직접 지정할 수도 있습니다.
- 기간 아래 최대 세 층의 머리글은 실제 병합을 포함해 모든 열의 이름이 있고, 기간마다 각 조합이 한 번씩 나오며, 모든 기간의 조합이 같을 때 읽습니다. 선택한 조합을 명시하고 생성 전에 확인받습니다. 이름이 없거나 조합이 중복되면 자동 처리를 거절합니다.
- 계층 번호가 있는 재정 표는 하위 줄을 빼고 최상위 항목을 비교합니다. 수익과 비용은 서로 다른 개념이므로 한 합계로 더하지 않습니다. 번호 없는 모호한 계층과 일부 피벗 배치는 여전히 지원하지 않습니다.
- 차트와 계산은 같은 숫자 규칙을 사용합니다. 읽지 못한 글자는 경고와 함께 비웁니다. 검사는 내장 엑셀과 숫자뿐 아니라 차트 점 개수도 확인합니다.
- 회계연도 종료월이 없거나 서로 다르면 6월로 대체하지 않습니다. 원본 기간 이름과 값은 보여 주되, 기간 완료 여부와 계산한 기간 비교는 유보합니다. 원본에 종료월을 적으면 계속할 수 있습니다.
- 날짜별 계산 문장의 현재 값이 원본 한 칸에서 직접 온 경우 표시 형식 색을 옮깁니다. 계산한 합계·평균·비율, 과거 비교값과 모델 문장은 템플릿 색을 지킵니다. 검정·흰색도 템플릿 색을 유지합니다.

- 구조화 머리글은 실제 내용이 있는 셀에서 찾아 이전의 300행·80열 밖도 탐색합니다. 최저/최고나 기관·직종 역할을 명시한 문법이 필요하며 임의의 계층을 추정하지 않습니다.
- CSV/TSV/TXT·지원 ODS 값·이름을 바꾼 XLSX 내보내기는 독립 원본 검산을 지원합니다. 지원하는 BIFF2–5/8 XLS·XLSB 셀은 독립 디코더로 검사하며 미지원 바이너리 기록/작업공간 변형과 미지원 ODS 기간 문법·표현은 부분 검증이고 텍스트·ODS 확장 예산은 셀 200만 개입니다.
- 사용한 수식 캐시는 제한된 독립 수식 검사를 거칩니다. XLS·XLSB 수식 표현·배열·외부 연결·알 수 없는 함수/형 변환·자원 초과는 부분 검증이며 저장할 수 없습니다. XLSX·ODS 하위 문법과 정확한 십진 디코딩 경계는 [신뢰성 계약](reliability-hardening.ko.md)에 명시합니다.
- 텍스트만 채워도 원본·직렬화 검사를 합니다. 지원하는 수치 비교·최고/최저 자리표시자와 Word 연결 평균은 독립 계산하지만 모든 해설·모델 문장 의미를 증명하지는 않습니다. 차트 정수·명시한 표시 정밀도가 숫자 컨테이너를 통과하지 못하면 차트를 거절합니다.
- 버블 템플릿은 명시한 X와 Y·크기 열 쌍, 음이 아닌 크기, 계열별 완전한 점이 필요합니다. 크기 캐시와 내장 데이터를 검사하고 모호한 열·빈 계열은 입력 오류로 알립니다.
- 작은 창의 상태 요약을 별도 행에 표시합니다. 증명 핵심에는 유리수 교차곱을 추가했으며 부동소수점 오차 예산·Fraction 정규화·일반 업무 선택은 그 증명 밖입니다.

명시한 XLSX 행 그룹 수준은 계층 합산 없이 설명 표로 보존합니다. 십진수·유리수 표시 반올림은 실제 증명한 판단 코드를 쓰고 그룹 집계는 정확한 유리수 중간값과 주어진 디코딩 오차 합의 증명을 사용합니다. 앱 평균·증감·비율도 유리수 중간값을 유지합니다. 원본 변환·공유 표시 서식기·다른 통계/선택 경로는 테스트·신뢰 경계입니다. 행마다 같은 가중치를 주는 비율 평균이 의도한 전체 비율과 같지는 않으므로 가중치·분모는 여전히 명시해야 합니다. [숫자 경계 안내](binary-verification.ko.md)를 참고하세요.

## 검증 근거와 현재 시험 범위

8차 측정은 고정한 v0.2.0 코드에 처음 보는 공개 파일 여덟 개를 사용했습니다. 여섯 개는 보고서를 생성하고 복합 양식 두 개는 거절했으며, 빈 차트·연도와 단위 누락·문장 과잉 차단을 찾았습니다. 수정에 사용한 뒤 이 입력은 회귀 자료입니다. 재실행을 새 공정 정확도 점수로 부르지 않습니다.

당시 거절한 두 유형에는 범위를 정한 원본 표 지원과 독립 회귀 검사를 추가했습니다. 표와 일반 분류·날짜·산점도 차트는 저장 전에 자동 검사하며 완료·부분 검증·차단을 구분합니다. 아직 릴리스하지 않은 소스는 텍스트·지원 수식까지 검증을 확장하고 부분 검증도 저장을 거절합니다. 작은 합산·일치·오차 비교 핵심은 Dafny로 증명해 실제 앱에서 사용하지만 앱 전체의 전 입력 증명은 아닙니다. [정확한 경계](verification.ko.md)를 확인하세요.

현재 범위에서는 기존 샘플 사용과 자동 검사로 충분하다는 프로젝트 결정을 적용합니다. 별도 실제 사용자 시험은 계속 제외합니다. 이후 요청한 새 Windows 시험은 v0.3.0의 동일 EXE로 완료했습니다. Office·별도 Python이 없는 새 오프라인 Windows 10 Pro 19045.3803 VM에서 19개 사례가 통과했습니다. 실제 PowerPoint 16.0.20326.20232로 호스트 보고서 18개와 실제 게스트 보고서 18개, 총 44슬라이드를 렌더링했고 게스트의 22장 이미지가 시각 검토한 호스트 이미지와 바이트 단위로 같았습니다. Windows 11·다른 물리 PC·비공개 회사 파일의 호환성이나 독립적인 사람의 시험을 입증하지는 않습니다.

이번 변경에 의존성을 추가하지 않았습니다. 프로젝트 MIT와 별도로 구성요소의 고지와 원본 자료의 라이선스를 그대로 유지합니다.

[환경 검증과 이전 시험 결정](testing-alternatives.ko.md), [개발 이력](development-history.ko.md)을 참고하세요. 이전의 시험 생략은 당시의 결정이며 완료한 Windows 10 VM 시험의 현재 상태가 아닙니다. 다른 오피스 제품을 설치하거나 호스트 보안·가상화 기능을 바꾸지 않았습니다.

## 추후 필요할 때의 재현 방법

현재 필수 시험이 아닌 참고 절차입니다. 구체적인 문제가 보고되면 사용이 허용된 해당 통합 문서와 템플릿의 로컬 사본을 준비합니다. 앱을 열기 전에 기대하는 시트·기간·단위와 원본 값 다섯 개를 적습니다. 실행 파일에서 파일을 고르고 F5로 그 값을 확인합니다. Ctrl+R로 수치를 바꾸고 Ctrl+G로 새 보고서를 저장합니다. PowerPoint에서 텍스트·표·차트와 차트의 데이터 편집을 열어 원본과 대조합니다. 의심되는 선택을 한 번 취소하고, 읽지 못하는 파일도 골라 복구되는지 확인합니다. 실행 파일 해시, Windows·Office 버전, 결과와 차이를 기록합니다. 회사 파일과 화면 사진은 비공개로 보관하세요. 실제 사람이 해야 하는 절차이며 스크립트 클릭을 사람의 시험으로 기록하지 않습니다.
